## 🚀 How to Use

1. **View locally** — Open `index.html` in any modern browser
2. **Deploy** — Copy the entire folder to your hosting service
3. **Customize** — Update contact info, links, and project details in the HTML file
4. **Add images** — Place project images in `assets/imgs/` (optional for now)
